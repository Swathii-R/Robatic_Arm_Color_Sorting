# Robotic Arm Color Sorting

## Overview

This repository documents a robotic arm color sorting project that uses computer vision and HSV color detection to identify different colored objects and sort them into designated locations.

**Topics Covered**

- Introduction to robotic arm color sorting
- Color detection using HSV color space
- HSV calibration and configuration
- Python programming using Jupyter Notebook
- Basic robotic arm movements and object sorting

**Project Files**

- "Color Sorting.ipynb" – Main notebook for color detection and sorting.
- "HSV_calibration.ipynb" – Used to calibrate HSV values for different colors.
- "HSV_config.txt" – Stores HSV configuration values for color detection.

**Learning Outcomes**

- Color Detection: Learned the basics of identifying object colors using computer vision.
- HSV Calibration: Understood how HSV values help distinguish different colors.
- Python Programming: Gained practical experience working with Jupyter Notebook.
- Robotic Arm Automation: Explored how color detection can be used to guide object-sorting operations.

**Technologies Used**

- Python
- Jupyter Notebook
- Computer Vision
- HSV Color Space
- Robotics
